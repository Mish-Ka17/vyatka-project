# vyatka-project
    Стек:
    - Laravel v13
    - Vite v8
    - Tailwind CSS v4

## Требования

- PHP 8.4+
- Composer 2
- Node.js 22+
- npm
- Open Server Panel 6.5+

## Установка модулей и настройка проекта

1. clone https://github.com/Mish-Ka17/vyatka-project.git ( клонирование проекта в .../OSPanel/home/ )

2. composer install  (установка PHP-зависимостей)

3. npm install  (установка Node-пакетов)

4. copy .env.example .env  (создание файла конфигурации .env)

5. php artisan key:generate  (генерация ключа Laravel)

#### Сборка production

6. npm run build  (сборка frontend для production)

## Запуск проекта локально

Проект разрабатан на фреймворке Laravel в среде Open Server 6

## Возможности - доступные страницы главного меню и "хлебных крошек":

- Главная страница
- Каталог товаров
- Страница категории
- Карточка товара
- Блог
- Страница статьи
- Модальное окно обратной связи (Контакты)
